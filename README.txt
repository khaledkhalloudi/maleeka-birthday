MALEEKA BIRTHDAY WEBSITE
========================

1. Keep index.html, style.css, script.js, and the photos folder together.
2. Open index.html in your browser to preview the website.
3. The six uploaded photos are already included in photos/photo1.jpg through photos/photo5.jpg.
4. Internet is only needed for the optional Google Fonts. The website and photos work locally.
5. To publish: create a GitHub repository, upload all three files and the photos folder, then enable GitHub Pages from Settings > Pages, deploying from the main branch and root folder.
6. The website is public once published. Anyone with the link may be able to see the photos, so share it thoughtfully.
